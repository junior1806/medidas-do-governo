# Medidas do Governo 1994–2026

Página com as principais medidas de cada governo com impacto nas contas públicas, de 1994 a 2026, e com a arrecadação, as despesas, os juros e a dívida federal no mesmo período.

Cada número tem o link da fonte oficial: Receita Federal, Tesouro Nacional, Banco Central e INSS.

**Abrir a página:** https://junior1806.github.io/medidas-do-governo/
